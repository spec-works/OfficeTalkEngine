OfficeTalkEngine
Table of Contents

Namespace OfficeTalkEngine.Execution

Classes

ExcelComExecutor

Executes OfficeTalk operations against a live Excel instance via dynamic COM. Uses late-bound COM to avoid dependency on Office PIAs. Requires Excel to be running with the target workbook open.

ExcelExecutor

Executes OfficeTalk operations on Excel documents using snapshot semantics.

PowerPointComExecutor

Executes OfficeTalk operations against a live PowerPoint instance via dynamic COM. Uses late-bound COM to avoid dependency on Office PIAs. Requires PowerPoint to be running with the target presentation open.

PowerPointExecutor

Executes OfficeTalk operations on PowerPoint documents using snapshot semantics.

WordComExecutor

Executes OfficeTalk operations against a live Word instance via COM Interop. Uses dynamic COM to avoid dependency on Office Primary Interop Assemblies. Requires Word to be running with the target document open. Changes appear instantly in the Word UI.

WordExecutor

Executes OfficeTalk operations on Word documents using snapshot semantics. All addresses are resolved before any mutations occur.

Interfaces

IOfficeTalkExecutor

Executes an OfficeTalk document against a target Office file, applying all operations with snapshot semantics.
